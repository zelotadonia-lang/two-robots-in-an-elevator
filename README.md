One robot compliments the other's actuators, then reports itself to HR — only to discover HR is also itself. A short, self-contained joke about workplace bureaucracy surviving the robot uprising, delivered as a deterministic one-liner.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, no trailing newline) and verifies the file contents by reading them back.
